- **価格の表記**: このドキュメントと公開ページは**すべて税抜**で揃える（従来は税込と税別が混在していた）

## 1. 半年で何が変わったか

### 変化1：Backlog が2027年1月に値上げし、安い入口が無くなる

現行4プランが3プランに統合され、いちばん安いプランが月2,700円から**月21,000円**に上がる。

| | 現行（〜2026年12月） | 新プラン（2027年1月〜） |
|---|---|---|
| 入口 | スターター ¥2,700 / 30名・5プロジェクト | エコノミー ¥21,000 / 15名・30プロジェクト |
| 実務ライン | スタンダード ¥16,000 / 人数無制限・100プロジェクト | ビジネス ¥36,300 / 無制限 |
| 上位 | プレミアム ¥27,000、プラチナ ¥75,000 | プロフェッショナル ¥100,000 |

既存契約は2027年1月1日以降の最初の更新日に移行する。うちの比較表は「Backlog スタンダード ¥17,600（税込）」を基準にしていたので、数字も前提も作り直しが要る。

### 変化2：「AIで操作できる」が全社の標準装備になった

この1年で主要ツールがすべてAIを載せた。差別化の軸としては使えなくなった。

- **Backlog**: AIアシスタントを2026年3月に正式提供。プレミアム以上
- **Jira**: Rovo が有料プランに標準搭載。クレジット制（1リクエスト10クレジット）
- **Asana**: AI Studio を全有料プランに、AI Teammates は個別見積り
- **Notion**: Notion Agent は Business 以上。自律エージェントは1,000クレジット$10の従量
- **monday / Linear / ClickUp**: いずれもエージェント提供済み。monday は2026年5月からAIクレジットが別売り

AIから直接ツールを操作する口（MCP）も、Atlassian・Linear・Notion・Asana・ClickUp・monday・Wrike が公式提供している。**うちの比較表の「AI/CLI操作 ◎」は、いまや横並び**なので格下げする。

### 変化3：チャットからタスクを拾う競合が生まれた

- **TaskLine**（taskline.jp）: LINEグループ専業。Free ¥0 / Basic ¥2,980 / Pro ¥9,800。カンバン・議事録化・日次サマリーまで
- **Slack**: 2026年3月に30以上の新機能を発表。Slackbot がエージェント化し、再利用できるAIタスクテンプレートを持つ
- **Chatwork**: AIアシスタントでタスク作成と日程調整を自動化
- **LINE WORKS AiNote**: AI議事録。2026年4月に話者認識と「次のステップ（ToDo抽出）」を追加。有償版2,900社

どれも**社内チャットの効率化**に寄っていて、社外の相手先との受け渡しは扱っていない。

## 2. うちの中身も広がった

当初は「クライアントワーク向けのプロジェクト管理」1本だった。いまは5つの塊がある。

1. **プロジェクト管理**: ボール管理・ガント・バーンダウン・多階層タスク・マイルストーン
2. **相手先ポータル**: アカウント不要で閲覧・承認・起票・見積もり確認。ベンダーポータルも別にある
3. **AI秘書**: LINE / Slack / Teams / Google Chat と接続し、会話からタスクを拾う。自社LINE公式アカウントでの配信、1対1メッセージ、期限リマインドまで
4. **ドキュメント**: Wiki・議事録の同時編集・決定事項の記録・ファイル・CSVの表ビュー
5. **お金の流れ**: 見積もり→承認→請求書（freee / MFクラウド / Misoca 連携）。代理店モードで原価と売値を分離

**比較相手が1グループでは足りない。** 表を2本に分ける。

## 3. グループA：クライアントワーク向けのプロジェクト管理

比較相手は AgentPM / Backlog / Jira / Linear / Notion / Rocketlane。Redmine は外した。受託・制作の現場で検討対象に挙がらなくなったため。

| | 状況 |
|---|---|
| **Backlog** | 国内の受託でいちばん当たる。2027年の値上げで入口が月21,000円になり、小規模の受け皿が空く |
| **Jira** | 大企業・開発組織。Rovo 標準搭載で強いが、1人あたり課金で日本語は翻訳ベース |
| **Notion** | 2026年にエージェント基盤化。ドキュメントとタスクを1か所に置く用途で正面から当たる。相手先共有は公開ページ止まり |
| **Linear** | 社内のSaaS開発チームで強い。エージェントとMCPの作り込みは主要ツールで最も進んでいる。相手先への共有は課題1件の共有リンク止まりで、UIは英語のみ |
| **Rocketlane** | 相手先ポータルを持つ数少ない製品。$19〜$99/人・月で5席から。ただし英語のみで、日本の受託の商習慣には合わない |

**空いている場所**: 相手先がアカウントを作らずに使えるポータルは、monday も ClickUp も持っていない（どちらもゲスト招待＝要アカウント）。専用ポータルを持つ Rocketlane・Teamwork は英語圏の大手向け。**「アカウント不要の相手先ポータル × 日本語 × 組織定額」は、いまも空いている。**

## 4. グループB：チャットからタスクを拾うAI秘書

比較相手は AgentPM / TaskLine / Slack / Chatwork / Notion。

| | 状況 |
|---|---|
| **TaskLine** | LINE専業。共通Bot1本なので自社名義では出せない。拾ったタスクはカンバンで止まり、案件の進行には乗らない |
| **Slack** | 社内のワークスペース内で完結。相手先がSlackを使っていない場合は届かない |
| **Chatwork** | 同上。タスク作成はできるが、期限の追いかけや承認の証跡は持たない |
| **Notion** | エージェントが Slack とメールをまたいで動く。ただしチャットグループに常駐する形ではない |

**うちが持っていて他社が持たないもの**: 相手先とのグループに入れること、自社の名前で届くこと、拾ったタスクがそのまま案件の進行・承認・請求につながること。

## 5. 比較表の作り直し方針

- **表を2本にする**。表Aがプロジェクト管理（6列）、表Bがチャット連携（5列）
- **「AI/CLI操作」の◎を落とす**。全社が持ったので差にならない
- **料金の行を税抜で統一する**。AgentPM Pro ¥14,800 と Backlog スタンダード ¥16,000 を同じ土俵で並べる
- **Backlog の料金比較を「現行」と「2027年新プラン」の2列にする**。いまの比較だけだと半年で嘘になる
- **人数無制限が要るチームには Backlog スタンダードのほうが安い**と正直に書く。ページの趣旨（向く場合と向かない場合を両方載せる）に沿う
