**目的: 同じようなモチーフ・プロンプトの連発を防ぐ。** サムネイルを作る前に必ずこの表を読み、
既出と被らないモチーフを選ぶ。生成・採用したら**その場で追記**する(あとでまとめては書かない)。

- 生成: agy(`japanese-blog-writing` スキルの「サムネイルを agy で作る」手順)
- 置き場: 公開バケット `task6-covers/`(記事) / `task6-covers/characters/`(キャラ)。デプロイ不要
- 作成日: 2026-07-28

## バナー方式(2026-07-28確定・現行の正)

記事カバーは **`BANNER_PROMPT.md`(支給プロンプト全文・変更禁止)によるエディトリアル広告バナー**。
メインコピー+箇条書き3行(縮小でも読める太さ)+TASK6ロゴ、実写モデル or キャラ、アンバー基調。
文字はすべて生成内で組む(字形の目視検品必須)。完成バナーは og:image に直用(合成しない)。

### 登場人物のローテーション(厳守・ワンパターン防止)

**生成前にこの台帳の「人物」列を見て、直近2件と違うタイプを選ぶ**(ユーザー指定があればそれが最優先)。

- タイプのプール: 若手女性 / 若手男性 / 中年男性 / 中年女性 / 年配男性 / 年配女性 /
  **キャラクター(ガント先生・アイビー先生・ゆあ)** / 人物なし(静物・小物のみ)
- ポーズも変える(立ち姿ばかりにしない): 座る / 歩く / 振り返る / 手元アップ / 後ろ姿 など
- 採用したら「人物」列に記録する

## 運用ルール

1. **生成前**: この表を読む → 禁止リストを避け、記事の主題を「もの」に翻訳したモチーフを決める
2. **生成後**: 採用した画像を台帳に1行追記 + 禁止リストへモチーフを移す + 候補プールから消す
3. 没カット(不採用)は記録不要。採用したものだけ書く
4. キャラ画像を作り直したら、旧ファイルは上書きせず新名で置き、参照切替後に台帳を更新する
