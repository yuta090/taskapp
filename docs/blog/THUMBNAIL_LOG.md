# TASK6 画像台帳(サムネイル・キャラ) v1.0

**目的: 同じようなモチーフ・プロンプトの連発を防ぐ。** サムネイルを作る前に必ずこの表を読み、
既出と被らないモチーフを選ぶ。生成・採用したら**その場で追記**する(あとでまとめては書かない)。

- 生成: agy(`japanese-blog-writing` スキルの「サムネイルを agy で作る」手順)
- 置き場: 公開バケット `task6-covers/`(記事) / `task6-covers/characters/`(キャラ)。デプロイ不要
- 作成日: 2026-07-28

## バナー方式(2026-07-28確定・現行の正)

記事カバーは **`BANNER_PROMPT.md`(支給プロンプト全文・変更禁止)によるエディトリアル広告バナー**。
メインコピー+箇条書き3行(縮小でも読める太さ)+TASK6ロゴ、実写モデル or キャラ、アンバー基調。
文字はすべて生成内で組む(字形の目視検品必須)。完成バナーは og:image に直用(合成しない)。

### 場面の決め方(2026-07-28ユーザー裁定・この順で決める)

1. **場所**: 記事の内容(主題・比喩・読者の現場)から場面を決める
   (例: 容量の記事→比喩「エレベーターの定員」→エレベーターホール / 資料回収→税理士事務所の受付)
2. **人物**: 台帳の「人物」列を見て、**直近2件と違うタイプ**を選ぶ(ユーザー指定が最優先)。
   プール: 若手女性 / 若手男性 / 中年男性 / 中年女性 / 年配男性 / 年配女性 /
   キャラクター(ガント先生・アイビー先生・ゆあ) / 人物なし(静物)
3. **ポーズ**: 場所ですることを演じる「動きのある瞬間」にする。台帳の直近と同じポーズは避ける。
   棒立ち禁止。例: 踏み出す / 受け取る / 確かめる / 振り返る / 手元アップ / 後ろ姿 / 座って書く
4. 採用したら「人物・ポーズ・場所」を台帳に記録する

⚠ 生成が無難に転んだら、ヘッダに「前回は無難だった。セルフチェックの『無難禁止』『構図の違和感』を
最大限効かせる」と明記して回し直す(効果は実証済み)。プロンプト全文使用は絶対(要約禁止)。

### レイアウトは自由(2026-07-29・ユーザー裁定)

> 別に人物が右じゃなくてもいいんやで
> そそ。レイアウトの自由さを止める必要はない

**配置にルールを作らない。** それまでの9本が全部「人物=右／文字=左」だったのは、単に毎回同じ
組み方をしていたからで、その配置が悪いわけでも、逆にしなければいけないわけでもない。
「人物は左」も新しい決まりにしない。毎回、記事に合う組み方を自由に選ぶ。

**固定するのは1つだけ: コピーが読めること。** 人物をコピーに重ねて文字が隠れた案は不採用にした
(「1行目は、終わった景色から。」の「は、」「わった」「景」が身体で消えた)。重ねて遊ぶなら、
コピーではなく色面・ライン・ロゴのほうで遊ぶ。

- 台帳の「モチーフ/コピー」列に、実際に採った配置も書いておく(次に作る人が既出を見られるように。
  縛るためではなく、見比べるため)
- 差し替えは上書きせず `-v2` で上げ、DBの参照を切り替える(CDNキャッシュ対策)

### 生成のたびにヘッダへ書いておくと手戻りが減ること

構図そのものを縛る指定はしない(前項のとおりレイアウトは自由)。効くのは、**毎回同じところで
崩れる細部**を先に潰しておくこと:

- 指定していない文字・英字・縦組みのコピーを勝手に足させない(左端に縦組み英字が混入した実例)
- 小道具(紙・白板・画面)の中にも年号・日付を書き込ませない(「2024年度 Q3」が紛れ込んだ実例)
- 崩れやすい漢字を名指しする(「箋」「景色」など)。中黒(・)を豆腐(□)にしないことも明記
- 箇条書きは縮小(横400px)でも読める太さ。極小の説明文・細字は禁止

**画像形式(2026-07-28〜)**: 表示=WebP(cwebp -q 80)・シェア用=同名JPEG併置(WebP非対応サービス対策)。
差し替え時は上書きせず新名(-v2等)でアップし、DBの参照を切り替える(CDNキャッシュ対策)。

**使用済みモチーフの禁止リスト(次作で使わない)**: 付箋+鉛筆 / ガント棒の引き直し /
エレベーターの定員(容量) / 会議室の白板 / 印刷した表を見比べる。
今後の候補プール(早い者勝ち・使ったら消す): 積み上がる書類と砂時計 / 茂みに転がるボール /
冷蔵庫(見える化) / 玉突きのドミノ / 郵便受けから溢れる封筒(催促) / 絡まった糸と解けた糸。

## 運用ルール

1. **生成前**: この表を読む → 禁止リストを避け、記事の主題を「もの」に翻訳したモチーフを決める
2. **生成後**: 採用した画像を台帳に1行追記 + 禁止リストへモチーフを移す + 候補プールから消す
3. 没カット(不採用)は記録不要。採用したものだけ書く
4. キャラ画像を作り直したら、旧ファイルは上書きせず新名で置き、参照切替後に台帳を更新する
