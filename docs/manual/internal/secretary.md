# AI秘書・チャット連携

AgentPM の「秘書」は、**ふだん使っているチャット（LINE・Slack・Chatwork など）に入って、会話の中の「やること」を拾い、タスクにする**しくみです。相手先とのやり取りを AgentPM に転記する手間をなくすのが目的です。

秘書は左メニューの **「事務所 → 秘書」** から開きます。

![秘書コンソールのメッセージ画面](/img/help/secretary.png)

---

## 秘書コンソールの4つのタブ

| タブ | できること |
|------|-----------|
| **メッセージ** | 秘書がやり取りした会話を読む。こちらから送ることもできる（回収依頼・確認依頼・リマインドの定型ボタンつき） |
| **秘書からの確認** | 秘書が「これはタスクにしていいですか？」と聞いてきたものに、社内で答える |
| **ツール連携** | 他のタスク管理ツールとつなぐ（→ [ツール連携](./integrations.md)） |
| **チャット連携** | LINE などのチャットをつなぐ・つなぎ直す |

---

## つなげるチャット

「チャット連携」タブの左側に、つなげる先が並びます。

| チャット | 状況 |
|---------|------|
| LINE | もっとも標準的な使い方。押せるボタン（承認・完了など）が届くのは現在 LINE だけ |
| Chatwork / Slack / Discord / Telegram / Microsoft Teams / Google Chat | 会話の読み取り・お知らせの送信に対応。ボタンは届かず、文字の合図で操作する |
| WhatsApp Business / Facebook Messenger | 1対1のやり取り専用。グループの申し送りには使わない |

![チャット連携（LINE）の画面](/img/help/secretary-connect.png)

---

## つなぎ方は2種類ある

### 1. 自分（社内の担当者）のチャットをつなぐ

**目的**: 承認のお願いや期限のお知らせを、自分のチャットで受け取れるようにする。

1. 「チャット連携」→ LINE →「**1. 自分のLINEをつなぐ**」を開く
2. コード（本人確認の合言葉）を発行する
3. 秘書との**1対1のトーク**にそのコードを送る

注意点:

- コードの**有効期限は15分・1回だけ**使えます
- **グループには貼らないでください**。本人確認用のコードです
- LINE は「友だち追加」しただけではつながりません。**追加したうえでコードを送る**必要があります
- 端末を増やしたいときは「別の端末をつなぐ」から追加できます

### 2. 相手先とのグループをつなぐ

**目的**: 相手先との会話から、決めごと・お願いを自動でタスクにする。

1. 「**2. 相手先とのグループLINEをつなぐ**」→「グループをつなぐ」を押す
2. つなぎたい**プロジェクト（相手先）**を選ぶと、合言葉（コード）が出ます
3. 合言葉を相手に渡す（口頭・紙・メールでも構いません）
4. 相手が秘書をグループに招待し、その**グループに合言葉を投稿**します
5. Discord・Google Chat など一部のチャットでは、投稿後に社内で**承認**すると会話の記録が始まります

![チャンネルの承認画面](/img/help/secretary-approvals.png)

チャットごとの違い:

| チャット | 相手にしてもらうこと | 補足 |
|---------|-------------------|------|
| LINE | 秘書を友だち追加 → グループに招待 → 合言葉を投稿 | ボタン操作が使える |
| Discord | サーバーに秘書を招待 → 記録したいチャンネルに合言葉を投稿 | すでに招待済みなら招待の手順は不要 |
| Google Chat | スペースにアプリを追加 →（管理者の承認が一度だけ必要）→ 秘書あてのメンションを付けて合言葉を投稿 | 管理者の承認前は、メンション宛のメッセージしか届きません |
| Slack / Chatwork / Telegram / Teams | 秘書をチャンネル（グループ）に招待 → 合言葉を投稿 | — |

> **相手先の担当者と1対1でつなぐ**（グループではなく個人あて）は **Pro プラン**の機能です。

## チャットで打てる合図（コマンド）

秘書は会話を読んでいますが、**確実に動かしたいときは決まった言葉を送ります**。

| 打つ言葉 | 何が起きるか |
|---------|-------------|
| `完了 3` | お知らせに付いていた番号3のタスクを完了にします |
| `一覧` | まだ終わっていないタスクを、番号を付けて返します |
| `タスク追加 ロゴ案を送る` | その場でタスクを1件作ります |
| `ヘルプ` | 使い方の一覧を返します |
| `練習` | 使い方の練習をひととおり案内します |

守ってほしい書き方:

- **`タスク追加` のうしろには必ず空白を1つ入れます**。空白がないと読み取れません（`完了 3` は空白なしでも動きます）
- **Chatwork の「返信」ボタンは使わないでください**。お名前が文の先頭に入り、合図として読み取れません。`完了 3` だけを送ります
- Google Chat では、**最初に合言葉を送るときだけ**秘書あてのメンションを付けます

各チャットの「説明欄」に使い方を貼っておくと、相手も迷いません。貼る場所はチャットごとに名前が違います（LINE＝グループの「ノート」、Slack＝チャンネルの「説明」、Discord＝チャンネルの「トピック」、Chatwork＝グループチャットの「概要」、Google Chat＝スペースの「説明」）。接続画面の「**使い方（コマンド一覧）**」から、貼り付け用の文章をコピーできます。

## 秘書のほうから届くもの

| 届くもの | 内容 | 備考 |
|---------|------|------|
| お知らせ（まとめ） | その日のやることを番号付きで送る | 無料プランは1日1回 |
| 期限リマインド | 決めた時刻に、担当のチャットグループへ声をかける | **Pro プラン**。タスクの詳細画面「リマインド（チャットへ通知）」で設定 |
| 完了の確認 | 期限を過ぎたタスクに「終わりましたか？」と確認する | 返事で `完了 3` と送れば、そのまま完了になります |
| はじめの挨拶 | つないだ直後に、使い方を1通だけ送る | — |

---

## 無料プランと Pro プランの違い

| | AgentPM秘書（無料） | AgentPM秘書 Pro |
|---|---|---|
| つなぎ方 | **共通LINE**（AgentPM 共通の共有アカウント） | **自社LINE**（事務所自身の LINE 公式アカウント。相手には自社名で届く） |
| 相手先との接続 | グループ単位 | 担当者（個人）単位も可 |
| タスクの拾い上げ | あり（**1日1回のまとめ**） | あり（**その場で**） |
| 時刻を決めたリマインド | — | あり |
| 送信量 | 上限あり（超えると控えめな動作になります） | 大きめ |

くわしくは [プランと請求](./billing.md) をご覧ください。

## うまくいかないとき

| 症状 | 確認すること |
|------|-------------|
| 合言葉を送っても反応がない | 秘書がそのグループに入っているか。Google Chat は管理者の承認が済んでいるか |
| 「完了 3」が効かない | Chatwork の「返信」ボタンを使っていないか。番号は**直前に届いたお知らせの番号**か |
| 「タスク追加」が無反応 | `タスク追加` のうしろに空白が入っているか |
| 承認や期限のお知らせが自分に届かない | 「1. 自分のチャットをつなぐ」が済んでいるか（グループをつないだだけでは本人には届きません） |
| 相手先に届かなくなった | 無料プランの送信上限に達していないか（接続画面の「今月の共通LINE送信」で確認できます） |
