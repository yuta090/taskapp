# 通知ガイド

「いつ・どこに・何が届くか」をまとめます。設定は「設定 → **通知設定**」です。

![通知設定の画面](/img/help/settings-notifications.png)

---

## 届き方は4つ

| 届き方 | 何が届くか | いつ届くか |
|--------|-----------|-----------|
| **受信トレイ**（アプリの中） | すべて | すぐ |
| **メール（すぐ送るぶん）** | 承認依頼など「**あなたの返事を待っている件**」 | 数分ぶんをまとめて、すぐ |
| **メール（1日1回のまとめ）** | それ以外 | 1日分をまとめて1通 |
| **ブラウザ・スマホの通知** | 承認依頼と、**自分に番が回ってきたとき**だけ | すぐ |

考え方はひとつだけです。**急ぎ（あなたが止めている件）はすぐ、それ以外は1日1回。**

### 静かな時間

**夜9時〜朝8時と土日**は、すぐ送るぶんを止めて、**翌営業日の朝**にまわします。ブラウザ・スマホの通知もこの時間は鳴りません。

---

## 通知設定でできること

| 設定 | 内容 |
|------|------|
| **ブラウザ通知** | パソコン・スマホに直接出す通知。スイッチを入れると、ブラウザから許可を求められます |
| **メール通知** | メール全体のオン・オフ |
| **通知の種類** | 下記の種類ごとにオン・オフ。**メールとブラウザ通知の両方に効きます**（切った種類はどちらにも届きません） |
| **ダイジェストメール** | まとめメールの頻度（オフ／毎日／毎週） |

### 通知の種類

| 種類 | 届くとき |
|------|---------|
| タスク割り当て | タスクが自分に割り当てられた／ボールが回ってきたとき |
| メンション | コメントで自分がメンションされたとき |
| 社内承認依頼 | 社内承認・レビューを依頼されたとき |
| 相手からの応答・承諾 | 相手先やメンバーが確認・回答したとき、招待を承諾したとき |
| 会議リマインダー | 予定された会議の前 |
| 期限リマインド | 期限が近づいたとき |

## iPhone・iPad で通知を受け取る

Safari で開いているだけでは通知が届きません。**ホーム画面に追加**してください。

1. Safari で AgentPM を開く
2. 共有ボタン（□に↑）→「**ホーム画面に追加**」
3. 追加されたアイコンから開く
4. 「設定 → 通知設定」で、もう一度ブラウザ通知のスイッチを入れる

---

## チャット（LINE・Slack など）に届けたいとき

秘書とチャットをつないでおくと、承認のお願いや期限のお知らせを**チャットで**受け取れます。つなぎ方は [AI秘書・チャット連携](./secretary.md) をご覧ください。

- 「自分のチャットをつなぐ」が済んでいないと、**グループをつないでも本人には届きません**
- 時刻を決めたリマインドは **Pro プラン**の機能です

Slack のチャンネルにプロジェクトの動きを流したい場合は [Slack連携のはじめかた](./slack-setup.md) をご覧ください。

---

## 届かないときの確認

| 症状 | 確認すること |
|------|-------------|
| メールが1通も来ない | 通知設定の「メール通知を有効にする」が入っているか。迷惑メールフォルダに入っていないか |
| 急ぎのメールが遅い | 夜9時〜朝8時・土日ではないか（翌営業日の朝にまとめて届きます） |
| ブラウザ通知が出ない | ブラウザ側で通知がブロックされていないか（アドレスバーのサイト設定から許可できます） |
| iPhone で通知が出ない | ホーム画面に追加したアイコンから開いているか |
| 特定の種類だけ来ない | 「通知の種類」でその種類が切られていないか |
| チャットに来ない | 自分のチャットをつないでいるか（[AI秘書](./secretary.md)） |

> アプリの中の**受信トレイには、設定に関係なくすべて記録**されています。「見落としたかも」と思ったら受信トレイをご確認ください。

---

## 通知疲れを防ぐコツ

- まとめメールを「毎日」にして、急ぎだけすぐ受け取る（既定の設定です）
- 自分に関係のない種類は切る（例: 会議に出ない方は会議リマインダーを切る）
- ブラウザ通知は、**返事を待たれている件だけ**に絞られています。切らずに使うのがおすすめです
