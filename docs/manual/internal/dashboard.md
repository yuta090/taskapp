# ダッシュボード

プロジェクトの全体状況を一目で確認できるページです。タスクの進捗、リスク、期限、クライアント対応状況などを集約表示します。

![ダッシュボード。残タスク・ボールの偏り・期限超過・レビュー待ちが一目で分かります。](/img/help/dashboard.webp)


---

## アクセス方法

左ナビゲーションのプロジェクト名をクリックし、「ダッシュボード」を選択します。

URL: `/:orgId/project/:spaceId/dashboard`

---

## 画面構成

ダッシュボードは以下のセクションで構成されています。

### 全体・メンバー別・今週を切り替える

画面上部のタブで表示を切り替えます。開いているタブは URL（`?view=members` / `?view=week`）に残るので、そのまま共有できます。

| タブ | 表示内容 |
|------|---------|
| **全体** | 下の KPI カードや期限切れなど、これまでのダッシュボード |
| **メンバー別** | 担当者ごとに、完了・確認待ち・進行中・着手予定・未着手の件数を積み上げた棒と、期限切れの数。行を押すとその人の残りのタスクが期限の早い順に開く。担当者のいないタスクは「担当なし」にまとまる |
| **今週** | 今週（月〜日）の完了・新しいタスク・決まったこと・新しい Wiki・更新した Wiki・開いた会議の数と先週との差、日ごとの完了と新規の棒、それぞれの一覧 |

「今週」の「更新した Wiki」は、前からあるページのうち今週更新したものです。先週の数は出しません（記録が最後に更新した日だけのため）。

### KPI カード（4枚）

画面上部に 4 つの指標カードが並びます。カードを押すと、同じ数え方で絞り込んだタスク一覧が開きます。

| カード | 表示内容 | 押すと開く一覧 |
|--------|---------|------|
| **アクティブ** | 未着手・完了を除いたタスク数。下に未着手と完了の数 | タスク一覧の「アクティブ」 |
| **ボール（社内/クライアント）** | `社内数 / クライアント数` 形式 | クライアントの数字を押すと「クライアント確認待ち」 |
| **期限超過** | 期限を過ぎた、完了していないタスク数。1件以上で赤色 | タスク一覧の「期限切れ」 |
| **レビュー待ち** | 確認待ちのタスクと、返事待ちの承認依頼があるタスクの数。1件以上でアンバー色 | タスク一覧の「レビュー待ち」 |

ボールを使わない運用なら、右上の「表示する項目」で **ボール（件数のまとめ）** を外すと、ボールのカードだけが消えます。

### 期限切れ

期限を過ぎたタスクを、承認待ち・クライアント確認待ち・タスクに分けて出します。各行にはタスク名・担当者・期限・過ぎた日数が並びます。担当者がいないタスクは「担当なし」と出ます。

---

### クライアント確認が必要

クライアントにボールがあるタスクのうち、フォローアップが必要なものを表示します。

#### 要フォロー（赤）

以下のいずれかに該当するタスクです。

- 期限超過（`due_date` が過去）
- ボールを渡して **7日以上** 経過 かつ 期限まで3日以内

#### そろそろ確認（アンバー）

以下のいずれかに該当するタスクです。

- ボールを渡して **5日以上** 経過
- 期限まで7日以内

各行にはタスク名・期限までの日数・渡してからの経過日数が表示されます。クリックするとタスク詳細に遷移します。

> **Tips**: 「クライアント確認が必要」セクションが空の場合は「現在フォローが必要なタスクはありません」と表示されます。

---

### マイルストーン進捗

アクティブなマイルストーンごとに以下を表示します。

| 項目 | 説明 |
|------|------|
| マイルストーン名 | クリック不可（表示のみ） |
| 期限 | 期限までの残日数 |
| リスクバッジ | 高リスク（赤）・中リスク（アンバー）・低リスク（緑）・完了（グレー） |
| プログレスバー | 完了タスク数 / 全タスク数 の割合 |

#### リスク判定ロジック

リスクレベルは直近14日間のタスク完了ペース（ベロシティ）と残タスク数から自動計算されます。

| 条件 | リスクレベル |
|------|-------------|
| 全タスク完了 | 完了 |
| 期限超過 | 高リスク |
| 14日間の完了タスクが 0 件 | 高リスク |
| 必要日数 / 残日数 > 1.5 | 高リスク |
| 必要日数 / 残日数 > 1.0 | 中リスク |
| 上記以外 | 低リスク |

---

### ボール所在

アクティブタスクのボール分布を棒グラフで表示します。

- **社内**（インディゴ）: 社内にボールがあるタスク数
- **クライアント**（アンバー）: クライアントにボールがあるタスク数

---

### 期限が近いタスク

直近 **7日以内** に期限を迎えるアクティブタスクを最大8件表示します。

- 期限超過: 赤色のドット
- 期限まで2日以内: アンバー色のドット
- それ以外: 緑色のドット

各行をクリックするとタスク詳細に遷移します。

---

### 直近の予定

今後予定されているミーティングを最大5件表示します。

- 日付（M/D形式）と時刻（HH:MM形式）
- ミーティング名

各行をクリックするとミーティング詳細に遷移します。

---

## 操作について

ダッシュボードは **読み取り専用** です。データの編集はタスク一覧やミーティング一覧から行ってください。
