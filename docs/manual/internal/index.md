# 開発会社向けマニュアル

AgentPM の開発チーム向け操作マニュアルです。プロジェクト管理、タスク管理、会議運営、仕様管理など、日々の業務で必要な操作方法を解説します。

---

## このマニュアルの読み方

上のカードが目次です。はじめての方は「はじめに・初期設定」→「タスク管理」の順にご覧ください。
チャット（LINE・Slack など）から使いたい方は「AI秘書・チャット連携」をご覧ください。

---

## クイックリファレンス

| 操作 | 方法 |
|------|------|
| プロジェクト作成 | 左ナビのプロジェクト一覧横「+」→ プリセット選択 → 名前入力 |
| タスク作成 | 右下の「+」ボタン |
| タスク詳細 | タスク行をクリック（右ペインに表示） |
| インスペクター閉じる | `Esc` キー |
| ボールパス | インスペクター内のボール切替（社内 ↔ 外部） |
| レビュー依頼 | インスペクター → レビューセクション → 「レビュー依頼」 |
| レビュー承認 | インスペクター → レビューセクション → 「承認する」 |
| 会議開始 | 会議詳細 → 「開始」ボタン |
| 議事録からタスク生成 | `- [ ] SPEC(/spec/path#anchor): タイトル` 記法 |
| フィルター | タスク一覧上部のフィルターバー |

---

## 基本概念

### ボール（Ball）
「次に誰がアクションするか」を明示する仕組みです。

| ボール | 意味 |
|--------|------|
| `internal`（社内） | 開発チームが対応中 |
| `client`（外部） | 外部（クライアント）の確認・回答待ち |

### タスクタイプ
| タイプ | 説明 |
|--------|------|
| `task` | 通常のタスク |
| `spec` | 仕様タスク（spec_path と decision_state が必要） |

### Amber-500 バッジ
黄色（Amber-500）のバッジが付いた要素は、外部（クライアントポータル）にも表示される項目です。
